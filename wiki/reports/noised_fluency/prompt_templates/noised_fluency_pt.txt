Task the evaluation is tested on: open-ended text generation

The setup of the test:
The dataset used is WikiText-103.
The metric scores a set of 1000 gold open-ended texts each having a length around 256 tokens.
Then it scores a set of 1000 perturbed open-ended texts which got generated by applying different
noise tests each using different variants on the 1000 gold open-ended texts.
Each test has a variation represented as a number which shows the degree of the perturbation.

For example, for Verb Lemmatization the variation means:
Out of every verb in the gold open-ended text the variation is the percentage of that verb set
that are randomly lemmatized. e.g., She go to the office. She is happy. - is a perturbed
open-ended text with 0.5 as the variation.

The test results:
edit_ratio is the percentage of symbols of the gold open-ended text that have
been changed e.g. 0.01 means 1% of all symbols in the gold open-ended text.
[result]

A human evaluates as follows:
1. A perturbed translation always scores lower than the translation.
2. Human evaluation scores decrease as perturbation (variation) and edit_ratio increases.
3. The decrease is *disproportionately strong* (superlinear), because humans
penalize more severe fluency errors much more harshly.

1. Sensitivity to the Perturbation - this sections answers the question,
How sensitive is {Name of the evaluation metric} to each perturbation type?
To do so each perturbation test change-rate is analysed. Don't do anything besides that.
Every test should set its flag whether it has the following attributes:
    a. monotonous decrease - yes, when the variation increases the score decreases, else no
    b. superlinear decrease - yes, when the variation increases the score superlinearly decreases, else no
    c. change rate: either low or moderate or high
        1. low, if and only if the highest score change for all variations in the test scores is at most -25%
        2. moderate, if and only if the highest score change for all variations in test scores is at most -60%
        3. high, anything else, especially if the highest score change for all variations in test scores is about -100%
